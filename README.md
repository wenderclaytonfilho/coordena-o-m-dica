# CoordMed

Sistema web para apoio à Coordenação Médica Hospitalar, desenvolvido para otimizar processos administrativos, controle de presença, relatórios assistenciais e gestão de informações médicas.

## 📋 Sobre o Projeto

O CoordMed foi desenvolvido para centralizar atividades rotineiras da Coordenação Médica, reduzindo processos manuais e facilitando o acompanhamento de informações estratégicas do hospital.

A plataforma reúne diversas ferramentas utilizadas no dia a dia da gestão médica, permitindo maior agilidade na tomada de decisões e no controle operacional.

---

## 🚀 Funcionalidades

### 👨‍⚕️ Presença Médica

* Registro de presença por setor;
* Controle de faltas;
* Trocas de plantão;
* Repasses;
* Substituições;
* Geração de relatórios em PDF;
* Exportação para Excel.

### 🏥 Gestão de Cirurgias

* Controle de procedimentos realizados;
* Separação por especialidade;
* Indicadores cirúrgicos;
* Relatórios mensais;
* Exportação de dados.

### 📄 Evoluções Médicas

* Importação de planilhas;
* Separação automática por médico;
* Consolidação de grupos médicos;
* Controle de duplicidades;
* Geração de planilhas organizadas.

### 📑 Relatórios

* Exportação em PDF;
* Exportação em Excel;
* Impressão otimizada;
* Relatórios personalizados.

## 💻 Como Utilizar

1. Clone o repositório:

```bash
git clone https://github.com/wenderclaytonfilho/coordmed.git
```

2. Entre na pasta do projeto:

```bash
cd coordmed
```

3. Abra o arquivo `index.html` em seu navegador.

Ou publique em qualquer hospedagem estática:

* GitHub Pages
* Vercel
* Netlify
